# 💊 Домашна аптечка

Приложение за телефон и таблет (iPhone, iPad, Huawei, Android), в което цялото
семейство вижда и поддържа **общ списък** с лекарствата вкъщи.

## Какво може

- **Общ семеен списък.** Всеки член влиза със свой имейл и парола. Това, което един добави, променя или изтрие, другите го виждат веднага.
- **Добавяне на лекарство:** име, снимка (от камерата или галерията), описание и срок на годност. Автоматично се записва кой го е добавил.
- **Подредба по азбука** с разделители по буква (А, Б, В…).
- **Търсене** по име или описание.
- **Цветни отметки за срока:**
  - ✅ зелено: валидно
  - ⚠️ оранжево: изтича скоро (по подразбиране до 30 дни, променя се от ⚙️ Настройки)
  - ⛔ червено и зачеркнато: изтекло
- **Филтри:** Всички / Изтичат скоро / Изтекли / Валидни, с брой до всеки.
- **Редакция и изтриване:** докоснете лекарството, за да промените име, описание, срок или снимка, или да го изтриете (с потвърждение).
- **Без интернет** се показва последният запазен списък.

## Еднократна настройка (около 15 минути)

### Стъпка 1: безплатна база данни (Supabase)

1. Отворете <https://supabase.com> → **Start your project** и влезте (например с GitHub акаунта си).
2. **New project**: име `apteka`, измислете парола за базата (запишете я), регион **Central EU (Frankfurt)** → **Create**.
3. Когато проектът е готов: меню вляво **SQL Editor** → **New query**. Поставете цялото съдържание на файла
   [`supabase/schema.sql`](supabase/schema.sql) и натиснете **Run**. Трябва да видите „Success“.
4. Меню **Authentication** → **Sign In / Providers** → **Email**: изключете **Confirm email** → **Save**.
   Така членовете на семейството влизат веднага, без да чакат писмо за потвърждение.
5. Меню **Project Settings** → **API** (или бутон **Connect**). Копирайте:
   - **Project URL** (като `https://abcd1234.supabase.co`)
   - ключа **anon / publishable**

   Изпратете ми ги или ги впишете във файла [`config.js`](config.js). Тези два реда не са тайна. Данните се пазят от правилата за достъп в базата: всяко семейство вижда само своите лекарства.

### Стъпка 2: приложението за Android / Huawei

След като промените са слети в `main`, GitHub сам изгражда приложението (около 5 минути).

1. На телефона отворете: **github.com/stodorovski-bg/desktop-tutorial/releases** (влезте в GitHub, ако хранилището е частно).
2. Натиснете **apteka.apk** → свалете → отворете файла.
3. Телефонът ще попита дали разрешавате инсталиране от този източник → **Разреши** → **Инсталирай**.

> **Huawei:** работи на **HarmonyOS 2, 3 и 4** (и EMUI), защото те пускат Android приложения.
> **HarmonyOS NEXT / 5** не пуска Android приложения и за нея е нужно отделно приложение.
>
> **Нова версия:** свалете и инсталирайте новия `apteka.apk` върху стария. Данните не се губят, защото са в облака.

### Стъпка 3: iPhone и iPad

Има два варианта:

- **Безплатно, веднага:** уеб версия със същия общ списък. В GitHub → **Actions** → **Публикуване** → **Run workflow**
  (изисква GitHub Pages, вижте по-долу). После отворете адреса в Safari → „Сподели“ → **„Добави към началния екран“**.
- **Истинско приложение:** изисква **Apple Developer акаунт (99 $ годишно)**. Проектът за iOS е готов в папка `ios/`.
  С акаунта приложението се разпространява до телефоните на семейството през **TestFlight**. Кажете ми, когато имате акаунт, и ще настроя автоматичното изграждане.

**GitHub Pages** (за уеб версията) при безплатен акаунт изисква публично хранилище.
Ако решите да го направите публично, кажете ми първо, защото ще преместя ключа за подписване на Android приложението в тайните настройки на GitHub.

## Как се ползва

1. **Първият човек** (например вие): „Нов профил“ → име, имейл, парола → **„Аз съм първият“** → име на семейството → **Създай**.
2. В ⚙️ **Настройки** ще видите **код от 6 знака**. Натиснете **📤 Изпрати**, за да го пратите по Viber или SMS.
3. **Останалите**: „Нов профил“ → **„Имам код“** → въвеждат кода → **Присъедини се**.

## Технически бележки

| Част | Технология |
|---|---|
| Интерфейс | HTML/CSS/JavaScript без рамки (`index.html`, `styles.css`, `app.js`) |
| Приложения | [Capacitor](https://capacitorjs.com): `android/`, `ios/` |
| Данни и вход | [Supabase](https://supabase.com): Postgres с Row Level Security, Auth, Storage, Realtime |
| Изграждане | `npm ci && npm run sync` (събира `www/` и го копира в двата проекта) |
| APK | `.github/workflows/android.yml`: подписан release APK, публикуван в Releases → `android` |

- Схемата (`supabase/schema.sql`) може да се пуска повторно без загуба на данни.
- Снимките се смаляват до 1200 px (JPEG) и се пазят в частно хранилище (`medicine-photos`). Показват се само с временни линкове.
- APK се подписва с `android/app/apteka.keystore`. Паролата е по подразбиране, освен ако не е зададена тайна `APTEKA_KEYSTORE_PASSWORD`.
  Ключът трябва да остане същият, иначе новите версии няма да се инсталират върху старите.
